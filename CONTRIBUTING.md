# Contributing to UNVRS

Thanks for looking. UNVRS is my personal project, open source under the
[MIT License](LICENSE): read it, run it, fork it, learn from it.

## Pull requests

It moves fast and is built largely by its own agents against the design in
[docs/design/](docs/design/), so I can't review outside code at that pace. Pull requests
will likely be closed without review. Please don't take it personally.

## What helps

- **Issues.** Bug reports with steps to reproduce, `unvrs doctor` output and your macOS and
  harness versions. Strip anything private from logs before you paste them.
- **Questions and ideas** about the design. Open an issue and tag it as a question.
- **Forks.** The MIT license lets you take UNVRS anywhere.

## Security

Don't open a public issue for a security problem. Report it privately through GitHub:
**Security → Report a vulnerability** on this repository.
